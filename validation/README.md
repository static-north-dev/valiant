# Valiant Validation

Generate typed validators from fluent C# or model attributes. Fluent rules can use native control flow and compose other validators. Results carry property paths, codes, messages, and severity. Debug builds can step through fluent rules, and Fast mode uses direct generated checks.

Install `StaticNorth.Valiant.Validation` for standalone validators, or select the integration you need. ASP.NET Core, OpenAPI, MediatR, and source-generated Mediator integrations bring in the core runtime and generator.
