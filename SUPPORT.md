# Support

Start with the documentation at https://valiant.staticnorth.dev.

- Use the bug issue form for reproducible defects.
- Use the feature issue form for new behavior or API proposals.
- Use the question issue form for usage and integration questions.
- Follow `SECURITY.md` for suspected vulnerabilities; never report them in a
  public issue.

Support is provided on a best-effort basis. Include package versions, target
framework, runtime, and a minimal reproduction whenever possible.
