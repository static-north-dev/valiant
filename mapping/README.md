# Valiant Mapping

Generate typed object mapping from C# declarations. Convention mapping handles compatible members and constructor arguments for immutable DTOs. Use `Configure` to take explicit ownership of a mapping, apply conditions, or compose nested mappers.

Install `StaticNorth.Valiant.Mapping`. It includes the runtime API and analyzer.

- [Conventions](https://valiant.staticnorth.dev/mapping/guides/conventions) and [explicit mapping](https://valiant.staticnorth.dev/mapping/guides/explicit-mapping)
- [Composition and dependency injection](https://valiant.staticnorth.dev/mapping/guides/composition-dependency-injection)
- [Runtime modes and diagnostics](https://valiant.staticnorth.dev/mapping/reference)
