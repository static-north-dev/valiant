# Valiant Endpoints for ASP.NET Core

Organize Minimal API routes into classes and groups. Valiant generates registration from `[ValiantEndpoint]` and `[ValiantEndpointGroup]`. Each endpoint still uses ASP.NET Core route builders, filters, and conventions.

Install `StaticNorth.Valiant.Endpoints.AspNetCore`. It includes the endpoint contracts and analyzer.
