# Valiant pre-release audit

Reviewed candidate `bc11b65` and the subsequent working-tree changes. Each pass lists the fixes and the verification performed.

## First pass

### Fix before release

1. **Settings masking misses dictionary keys.** Runtime projection applies the sensitive-name policy to schema properties such as `Key` and `Value` and does not apply it to actual dictionary keys. Mask dictionary values by key before returning projected runtime values. [Runtime projection](../../settings/src/StaticNorth.Valiant.Settings.AspNetCore/ValiantSettingsSchemaDocumentFactory.cs#L183)
2. **Query rebinding can run after validation.** A route filter added inside `Map` runs before the appended `[AsParameters]` rebinding filter. Complete binding before validation and cover route and group filters. [Route registration](../../endpoints/src/StaticNorth.Valiant.Endpoints.AspNetCore/ValiantEndpointRouteBuilderExtensions.cs#L106)
3. **The generated `TryParse` shim affects other routes using the same type.** It returns success with a default value even when the route has no Valiant rebinding filter. Scope binding to participating routes or diagnose unsupported reuse. [Shim emission](../../endpoints/src/StaticNorth.Valiant.Endpoints.AspNetCore.SourceGeneration/ValiantEndpointGenerator.cs#L1888)
4. **Constructor-only structs lose mapped data.** Reproduced with a source coordinate of 42 mapping to 0. Select usable struct constructors in both generated and Debuggable mapping. [Constructor selection](../../mapping/src/StaticNorth.Valiant.Mapping.SourceGeneration/ValiantMappingGenerator.cs#L1352)
5. **Cyclic object graphs can exhaust the serializer stack.** Dot-notation and deep-object serialization recurse without a bound. Return a structured error when the serializer encounters a cycle or exceeds the traversal limit. [Serializer traversal](../../endpoints/src/StaticNorth.Valiant.Endpoints.AspNetCore/Query/QueryStringSerializer.cs#L214)

### Correctness and API

6. **Mapper emission loses C# keyword escaping.** Reproduced with `@event` in a source property and constructor parameter. Escape identifiers wherever generated syntax refers to them. [Constructor emission](../../mapping/src/StaticNorth.Valiant.Mapping.SourceGeneration/ValiantMappingGenerator.Emission.cs#L301)
7. **`[SetsRequiredMembers]` constructors still trigger `VLM006`.** Reproduced with a constructor that initializes the required member. Honor the constructor attribute while preserving explicit mappings. [Required-member analysis](../../mapping/src/StaticNorth.Valiant.Mapping.SourceGeneration/ValiantMappingGenerator.cs#L1130)
8. **Inherited `[FromQuery]` properties are missed.** A derived request with a query property on its base class received no generated `BindAsync`. Inspect visible inherited properties in both request-binding discovery paths. [Discovery](../../endpoints/src/StaticNorth.Valiant.Endpoints.AspNetCore.SourceGeneration/ValiantEndpointGenerator.cs#L649)
9. **Rebinding can reject values ASP.NET Core already parsed.** Valiant's conversion set is narrower than native binding, including for `DateOnly` and custom `TryParse` types. Rebind only members owned by Valiant. [Property binding](../../endpoints/src/StaticNorth.Valiant.Endpoints.AspNetCore/Query/QueryStringParser.cs#L622)
10. **Struct query models with implicit constructors fail.** A struct with a public `init` property returned `UnsupportedQueryType`. Support value-type initialization or report the unsupported shape during generation. [Object construction](../../endpoints/src/StaticNorth.Valiant.Endpoints.AspNetCore/Query/QueryStringParser.cs#L672)
11. **Single string collection items can be mistaken for JSON.** A list containing the literal `[]` serialized successfully and then failed to parse with default options. Define unambiguous literal handling. [Collection parsing](../../endpoints/src/StaticNorth.Valiant.Endpoints.AspNetCore/Query/QueryStringParser.cs#L428)
12. **Complex collections serialize to unparseable strings.** A list of records emitted `ToString()` output and reported success. Use a matching JSON representation when enabled or return a structured unsupported-shape error. [Collection serialization](../../endpoints/src/StaticNorth.Valiant.Endpoints.AspNetCore/Query/QueryStringSerializer.cs#L140)
13. **Aliases containing query syntax do not match.** A dotted alias is split before binding compares the complete name. Match root aliases before interpreting path syntax or diagnose unsupported aliases. [Key parsing](../../endpoints/src/StaticNorth.Valiant.Endpoints.AspNetCore/Query/QueryStringParser.cs#L180)
14. **Hidden properties can blank the settings runtime view.** Reproduced when reflection found two properties with the same name and different types. Resolve the declaration selected by the schema generator. [Runtime lookup](../../settings/src/StaticNorth.Valiant.Settings.AspNetCore/ValiantSettingsSchemaDocumentFactory.cs#L170)
15. **`configure: true` silently skips struct binding.** Report a generator diagnostic when a model explicitly requests Options binding and cannot receive it. [Settings generation](../../settings/src/StaticNorth.Valiant.Settings.SourceGeneration/ValiantSettingsGenerator.cs#L140)
16. **OpenAPI leaves `null` valid for `NotNull`.** Reproduced a required property whose schema still allows `string | null`. Apply nullability as well as presence. [Schema transformer](../../validation/src/StaticNorth.Valiant.Validation.AspNetCore.OpenApi/ValiantValidationSchemaTransformer.cs#L183)

## Second pass

### Fix first

21. **Generated validator constructors bypass factory-only initialization.** Reproduced with a validator whose private constructor sets a minimum to 10. The factory-created validator rejected 1, while the generated public constructors let DI instantiate it with the default minimum of 0. Preserve explicit constructor accessibility and invariants. If automatic registration cannot construct a validator, diagnose it or let the author supply a factory. [Constructor emission](../../validation/src/StaticNorth.Valiant.Validation.SourceGeneration/ValiantGenerator.Emission.cs#L178)
22. **The docs advisory gate can pass without a completed audit.** npm uses exit status 1 for advisory findings and can also return it with a JSON error. The script treats a missing `vulnerabilities` object as an empty report and prints the success message. Require a complete audit report before applying severity policy. [Audit command](../scripts/audit-dependencies.js#L52)
23. **Generated DI extensions collide across projects.** A host referencing two independent mapper libraries failed with `CS0121` on `AddValiantMappers()`. Both libraries emit the same public extension and namespace. Validation and Settings emit the same public registration pattern. Provide an assembly-specific registration entry point and cover a host that references two libraries. [Mapper DI emission](../../mapping/src/StaticNorth.Valiant.Mapping.SourceGeneration/ValiantMappingGenerator.Emission.cs#L180)
24. **Property-chain `FailFast` is lost after `Children` and `ForEach`.** Reproduced both paths recording a nested failure and still running the following check in the same chain. Mark the property chain as failed when a nested rule reports a failure. Cover sync and async completion. [Child validation](../../validation/src/StaticNorth.Valiant.Validation/ChildPropertyValidationExtensions.cs#L52), [Collection validation](../../validation/src/StaticNorth.Valiant.Validation/CollectionPropertyValidationExtensions.cs#L320)

### Correctness and consumer coverage

25. **A default .NET Standard 2.0 consumer cannot compile generated mapping.** The SDK 11 probe compiled user source but failed with `CS8370` on generated `#nullable enable` under the target's default C# 7.3. Setting C# 8 made this mapping probe pass. Declare the supported language version per package, cover it in a consumer build, and provide a clear diagnostic for unsupported configurations. [Generated file header](../../shared/src/StaticNorth.Valiant.SourceGeneration/ValiantSourceBuilder.cs#L7)
26. **A validator's dependency name can collide with a generated constructor parameter.** A dependency named `valiantValidationOptions` reproduced `CS0100`. Reserve a unique generated name against the selected constructor's existing parameters. [Constructor parameter emission](../../validation/src/StaticNorth.Valiant.Validation.SourceGeneration/ValiantGenerator.Emission.cs#L210)
27. **`NotEmpty()` accepts empty generic-only collections.** An empty `HashSet<string>` returned false from `IsEmpty`. Count discovery only checks non-generic `ICollection`. Handle generic counted collections in both generated and runtime validation. [Count discovery](../../validation/src/StaticNorth.Valiant.Validation/ValidationChecks.cs#L166)
28. **Collection membership ignores custom comparers.** A case-insensitive set reported that it contained the requested value, while Valiant returned false. Use the collection's native membership operation when available, then fall back to enumeration. [Membership helper](../../validation/src/StaticNorth.Valiant.Validation/ValidationChecks.cs#L297)
29. **Completing a validation context twice duplicates failures.** In the probe, two calls to `ToResult()` returned counts of 1 and 2 for one check. A retry after partial execution has the same underlying state problem. Make completion idempotent or explicitly reject reuse. [Context completion](../../validation/src/StaticNorth.Valiant.Validation/ValidationContext.cs#L249)
30. **Settings Options validation runs only the last registered validator.** The sync and async adapters resolve one `IValidator<T>`. If two packages each register a validator for the same Options model, the behavior differs from MVC, Minimal APIs, and mediator integrations, which enumerate validators. Validate all registrations or reject the ambiguous setup. [Options adapter](../../settings/src/StaticNorth.Valiant.Settings.Validation/ValiantSettingsValidationServiceCollectionExtensions.cs#L46)
31. **Settings runtime selection can resolve the wrong assembly's model.** The runtime lookup uses the CLR full name, section, and display name. Distinct model types from two assemblies can share all three and the endpoint always returns the first match. Use a stable identifier that includes assembly identity. [Settings selection](../../settings/src/StaticNorth.Valiant.Settings.AspNetCore/ValiantSettingsUiEndpointRouteBuilderExtensions.cs#L44)
32. **Settings generation duplicates repeated type branches.** A seven-type model with three siblings per level produced 3,279 schema entries and 3.79 MB of generated C#. The depth guard limits one path but does not bound total expansion. Reuse equivalent subtrees and add a generation budget for unusually large schemas. [Schema expansion](../../settings/src/StaticNorth.Valiant.Settings.SourceGeneration/ValiantSettingsGenerator.cs#L631)

### Release workflow

33. **The verification set and the publication set differ.** The verifier checks packages for the requested version, while upload and NuGet push use broad globs. Unexpected versions in the output directory could be published without passing the same checks. Use a fresh version-specific output directory and publish the verified manifest. [Package verifier](../../smoke/StaticNorth.Valiant.PackageVerifier/Program.cs#L45), [Upload and publication](../../.github/workflows/release.yml#L103)
34. **A duplicate NuGet version can make publication look successful.** `v1.4.0` and `1.4.0` normalize to the same version. If the second tag points to another commit, `--skip-duplicate` can report a successful run while leaving the earlier packages on the feed. Verify already-published package provenance before treating a duplicate as a successful retry. [Version normalization](../../.github/scripts/derive-release-version.sh#L4), [NuGet push](../../.github/workflows/release.yml#L140)
35. **Package validation has no previous-release baseline.** Candidate package validation checks the assets within the new package but has no configured comparison against the last published version. Add a baseline for existing packages and keep approved compatibility exceptions explicit. [Package validation settings](../../Directory.Build.targets#L42)
36. **Tag validation rejects valid prerelease identifiers.** Reproduced with `v1.4.0-rc--hotfix`. SemVer permits hyphens within any nonempty prerelease identifier. Accept that grammar while continuing to reject leading zeroes in numeric identifiers and build metadata under the project's policy. [Tag parser](../../.github/scripts/derive-release-version.sh#L7), [SemVer 2.0](https://semver.org/spec/v2.0.0.html#spec-item-9)

## Third pass

37. **Settings rescans reflection metadata for each property.** Runtime projection now caches the readable properties of the declared type and preserves the derived declaration when a property is hidden.
38. **Nested bracket arrays lose items or produce invalid keys.** Dot paths and deep-object paths now compose with bracket and indexed-array syntax. Parsing enforces both configured formats.
39. **An unsupported JSON collection can throw during binding.** The parser returns an `UnsupportedQueryType` error for a target the JSON deserializer cannot construct.
40. **Whole-request binding can omit a required query property.** Missing required members return `MissingQueryValue` using the query alias. Constructors marked with `SetsRequiredMembersAttribute` can supply defaults.
41. **OpenAPI loses nullability constraints on referenced properties.** Validation applies constraints to the occurrence of the reference and preserves the shared component.
42. **Optional constructor defaults are ignored in mapping.** Generated mapping and Debuggable mapping use declared defaults when a rule supplies no constructor argument.
43. **Generated validators fail to forward by-reference arguments.** Constructor chaining preserves parameter modifiers. Validators without a public by-value constructor can be registered through a factory.
44. **The single-use guard allocates a separate object per validation context.** The deferred rule list carries the guard and item contexts continue to share it.
45. **Count checks skip generic-only collections.** The helpers, fluent count rules, and count attributes handle enumerable collections. Sequence traversal stops once it can decide the bound.
46. **Local package verification sees packages from earlier versions.** The pack project stages each version in its own default directory and retains the explicit output path override used by release CI.
47. **The integrated API guide pins 1.2.1.** The guide installs the latest stable packages and shows how to pin a specific version.

### Verification

The locked restore succeeded. Both the Debug and Release builds reported zero warnings, and all 781 .NET tests passed in each configuration. All 75 docs tests, both site builds, and generated artifact checks passed.

The default local pack command staged the packages under `artifacts/packages/1.2.1-ci.1` with earlier packages still present in the parent directory. All ten package pairs passed verification and API compatibility checks against 1.2.1. The eight runnable consumers, the .NET Standard 2.0 compile check, and the macOS arm64 Native AOT smoke passed. The AOT linker emitted debug-symbol warnings.

The 128-property runtime settings benchmark improved from 136.2 µs and 181,371 B per operation before these fixes to 37.1 µs and 40,469 B afterward. The original baseline was 37.4 µs and 46,971 B. Runtime validation with ten children improved from 1.23 µs and 6,712 B to 1.15 µs and 6,448 B. Its original baseline was 1.17 µs and 6,360 B. The shared completion guard retains eight bytes of storage per context.

All eight generated Validation benchmark cases allocated zero bytes per operation. The all-failures case measured 3.95 ns after the fixes and 3.96 ns at baseline in the reverse-order repeat.

### Benchmarks

BenchmarkDotNet compared the source immediately before this pass with the updated source on .NET 11 and the same macOS arm64 host. The matched Release runs covered 28 cases, including 13 Mapping cases, eight generated Validation cases, and seven runtime cases. No case allocated more memory.

Query parsing went from 2,848 to 2,496 B/op at approximately 0.93 µs/op. Query serialization improved from 553 to 475 ns/op and from 1,656 to 1,472 B/op.
